# Componentes

| Componente | Responsabilidad |
|---|---|
| `FRONTEND/src/presentation` | Páginas, componentes, hooks y rutas. |
| `FRONTEND/src/application/store` | Estado global Redux y acciones por dominio. |
| `FRONTEND/src/domain` | Tipos y esquemas TypeScript. |
| `FRONTEND/src/infrastructure/api` | Axios, Firebase y APIs del backend. |
| `services/api-gateway` | Nginx, proxy y rutas públicas. |
| `services/auth-service` | Identidad y autenticación. |
| `services/user-service` | Usuarios, perfiles y roles. |
| `services/regulation-service` | Regulaciones y normas. |
| `services/evaluation-form-service` | Formularios, secciones y preguntas. |
| `services/compliance-service` | Respuestas, puntajes e informes. |
| `services/audit-service` | Auditorías y seguimiento. |
| `services/notification-service` | Notificaciones y correo. |
| `docker-compose.yml` | Orquestación local de frontend y backend. |
